# Sample output of the Figma tooling

What the tool produced from one HTML file — nothing here is typed by hand; every value comes out of the browser render.

| File | What it is |
| --- | --- |
| `code.js` | Figma plugin: creates the variables, text styles, auto layout, component and component properties |
| `manifest.json` | Plugin manifest for the file above |
| `tokens.json` | Design tokens in DTCG format |
| `design.json` | The measured architecture the plugin consumes |
| `main card.html` | The source HTML that was read, rendered and measured |
| `Forge - Figma board (personal).pdf` | The handoff board as a PDF |
